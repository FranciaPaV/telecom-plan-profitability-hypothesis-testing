# Telecom Tariff Revenue Analysis and Hypothesis Testing

## Objective
Determine which prepaid telecom plan generates higher average revenue using customer behavior analysis and statistical testing.

## Context
A telecom company offers two prepaid plans and wants to optimize its marketing budget by promoting the most profitable option.

## Data
Customer usage data including:
- Calls
- Messages
- Internet usage
- Monthly revenue by plan

## Analysis
The project included:
- Monthly revenue calculation per user
- Descriptive statistics
- Hypothesis testing to compare plan profitability
- Regional revenue comparison

## Tools
- Python  
- Pandas  
- SciPy  
- Matplotlib  
- Jupyter Notebook  

## Key Insights
- Usage patterns differ significantly between plans
- Statistical testing supports data-driven pricing decisions
- Revenue analysis helps guide marketing investment
